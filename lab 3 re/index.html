Lab 3

Published on October 3, 2026 by Bishal Budhathoki

In this lab, I added style to my webpage for the first time. Seeing plain HTML turn into a colorful and organized page made the work feel much more interesting. I learned how CSS can improve the appearance of a website.

What I Learned

  1. Linking an external stylesheet using the link element
  2. Writing CSS rules for elements, classes, and IDs
  3. Using colors, fonts, margins, and padding
  4. Validating HTML and CSS with W3C tools

I also learned that keeping content in HTML and design in CSS makes a webpage easier to manage and update. These resources helped me:

  • MDN CSS Documentation
  • W3Schools CSS Tutorial
