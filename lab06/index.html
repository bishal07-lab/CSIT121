1. Introduction

For this assignment, I evaluated the official website of the Community College of Baltimore County (CCBC). The website provides information about academic programs, admissions, registration, student services, and other college resources.

Website: https://www.ccbcmd.edu/

My goal was to evaluate how the website organizes information, how easy it is to navigate, and how its design supports students and other visitors.

2. Website Organization and Content

There are various kinds of information available on the website of CCBC that are useful for current students, future students, and the general public as well.

The website uses navigation links and grouped information to help visitors find what they need. This organization is useful because the college offers many programs and services.

However, new visitors may need some time to learn where certain information is located. Clear labels and a consistent organization can make the website easier to understand.

3. Visual Design and CRAP Principles

The CRAP principles stand for Contrast, Repetition, Alignment, and Proximity. These principles help designers organize information and make websites easier to read.

Contrast

The website uses headings, colors, and different text styles to separate information. Good contrast helps visitors recognize important content.

Repetition

Repeated navigation styles, headings, and page elements help create a consistent experience. Consistency makes it easier for users to learn how the website works.

Alignment

Aligning text and page elements helps visitors follow the content. A clear layout makes information easier to scan.

Proximity

Related information should be placed close together. Grouping related links and content helps visitors understand which information belongs together.

4. Navigation and Usability

Navigation is important because users should be able to move between sections and find information without unnecessary confusion. The CCBC website provides navigation links for its different resources.

One advantage is that the website offers information that students usually require, like academic programs and admissions information. Nevertheless, since there is a lot of information on the website, some people might find it difficult to locate a particular page.

I recommend using clear link names, keeping navigation consistent, and making important student resources easy to locate. The website should also work well on mobile devices.

5. Accessibility

Web accessibility means making a website usable for people with different abilities, including people who use screen readers, keyboards, or other assistive technologies.

Accessibility is important for a college website because students and visitors need equal access to information and services.

Useful accessibility practices include providing meaningful alternative text for informative images, using properly organized headings, labeling navigation regions, maintaining readable color contrast, and ensuring interactive elements work with a keyboard.

6. Accessibility Checker Results

I tested the CCBC homepage using the Accessibility Checker on October 24, 2026. The report marked the website as non-compliant and found 46 accessibility issues.

Scan Results

  • Website tested: https://www.ccbcmd.edu/
  • Total issues: 46
  • Critical issues: 5
  • Serious issues: 41
  • Moderate issues: 0
  • Minor issues: 0

Issues by Category

  • Tabs: 35 issues
  • General: 7 issues
  • Landmarks: 2 issues
  • Interactive content: 1 issue
  • Breadcrumbs: 1 issue

Problems Found

Problems were found with tab panel elements that lacked the corresponding tab, which might lead to confusion among screen reader users. Another issue was associated with the breadcrumb navigation section, which lacked a proper label. Additionally, there was a problem with the main navigation landmark.

What Passed

The report also showed some successful checks. For example, the homepage had a page title, specified its language, allowed the viewport to be resized, and included alternative text for the images checked.

My Recommendations

I recommend fixing the relationships between tabs and their panels, adding clear labels to navigation regions, and making sure screen reader users can understand the website's navigation. The college should review the critical and serious issues and test the website with assistive technologies.

This scan helped me understand that accessibility includes more than visual design. A website also needs to work properly for people who use screen readers and other assistive technologies.

7. Recommendations for Improvement

According to my analysis, it is recommended to make the website navigation as easy and clear as possible. Essential information for students must be accessible and the names of links should describe the destination pages.

The college should also address the issues identified by the Accessibility Checker. Correcting the tab relationships and navigation labels could improve access for people who use assistive technology.

Finally, the website should be tested on different screen sizes and with keyboard navigation. Automated accessibility scans are useful, but manual testing is also important.

8. Conclusion

Overall, the CCBC website provides important information about college programs and services. Its content helps students and visitors find resources related to college life.

However, the Accessibility Checker report identified issues that should be reviewed and corrected. Improving navigation, tab controls, and accessibility labels could make the website easier to use for more people.

This assignment helped me understand how organization, visual design, usability, and accessibility work together to create a better website experience.
